Портфолио-резюме — Хамидов Ю. Ш.
========================================

Привет! Это моё одностраничное портфолио-резюме. Сделал его на чистых
HTML, CSS и JavaScript — без фреймворков, без библиотек, без бэкенда
и без сборки. Просто три файла, которые открываются в браузере.


Что внутри
----------

index.html   — разметка страницы

style.css    — стили

script.js    — вся клиентская логика

README.md   — этот файл

Как устроен script.js

  На JS сделал пять вещей, которые реально нужны на странице:

   1. Валидация формы обратной связи
      Проверяю имя (минимум 2 символа), email (регуляркой) и сообщение
      (минимум 10 символов). Ошибки показываю под каждым полем,
      статус отправки — в отдельном блоке. Фокус переводится
      на первое невалидное поле.

   2. Плавная прокрутка по якорям
      По клику на пункт меню страница плавно едет к секции,
      а в адресной строке обновляется hash. Заодно подсвечиваю
      активный пункт меню при скролле.

   3. Анимация появления секций
      Через IntersectionObserver добавляю класс .is-visible,
      когда секция появляется в зоне видимости. Каждая секция
      анимируется один раз.

   4. Кнопка «Наверх»
      Появляется, когда проскроллил больше 400 px. По клику —
      плавный возврат к началу страницы.

   5. Динамический год в копирайте
      Подставляю текущий год через new Date(), чтобы не забывать
      обновлять руками.

  Если IntersectionObserver вдруг недоступен — секции просто
  показываются сразу, без анимации. Всё работает.


Как опубликовать
----------------

Сборка не нужна — это статика, её можно положить куда угодно.

GitHub Pages:
  1. Загружаю index.html, style.css и script.js в корень репозитория.
  2. Settings → Pages.
  3. Source: ветка main, папка / (root).
  4. Сайт будет доступен по адресу
     https://<username>.github.io/<repo>/

Netlify:
  — перетаскиваю папку с файлами в окно деплоя;
  — build command оставляю пустым, publish directory — . (корень).

Vercel:
  — Framework preset: Other;
  — build command и output directory оставляю пустыми.

Локально:
  — просто открываю index.html в браузере;
  — или запускаю python3 -m http.server 8000 и смотрю
    на http://localhost:8000


Что стоит знать про ограничения
-------------------------------

- Бэкенда нет. Форма обратной связи ничего никуда не отправляет:
  валидация и «успешная отправка» имитируются на клиенте.
  Для реальной отправки нужно подключать серверный обработчик
  или внешний сервис.

- Только тёмная тема. Переключателя нет и не планируется.

- В портфолио нет реальных картинок проектов — вместо них
  стилизованные CSS-блоки с номерами. Так честнее, чем
  вставлять битые ссылки.

- Аватар подгружается с внешнего URL. Если источник недоступен,
  картинка не отобразится.

- Контакты — заглушки: ivanov.ivan@example.com, +7 (000) 000-00-00
  и ссылка на ВК. Реальные персональные данные не использую.

- Никакой аналитики, куки и трекинга — сайт не собирает данные
  о посетителях.

- Ориентируюсь на современные браузеры: CSS Grid, Flexbox,
  :focus-visible, clamp(), aspect-ratio, IntersectionObserver.
  Очень старые браузеры (например, IE) не поддерживаются.

Что реализовано на JavaScript
-----------------------------

Коротко, чтобы было видно с первого взгляда:

  — интерактивная форма обратной связи с валидацией полей
    и выводом сообщений об ошибках/успехе без перезагрузки страницы;
  — плавная прокрутка по якорным ссылкам навигации
    и подсветка активного пункта меню при скролле;
  — анимация появления секций при прокрутке (IntersectionObserver);
  — кнопка «Наверх» с плавным возвратом к началу страницы;
  — динамический год в копирайте футера.
